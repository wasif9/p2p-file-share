# Front-end using GioUI


## Requirements
[Go](https://go.dev/dl/)


## Dependency
[Gio UI](https://gioui.org/)
- Run ``go install gioui.org/cmd/gogio@latest`` to install the latest GioUI


## (Windows) Run & Build
1. Run ``go run .`` to execute the frontend
2. Run ``go build -ldflags "-s -w -H windowsgui"`` to build an executable binary
